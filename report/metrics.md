# Coupling metrics

[← Module report](README.md) · generated by `./gradlew graph`

`Ca` counts the modules that depend on this one, `Ce` the modules it depends on.
`I` is instability, `Ce / (Ca + Ce)`. `A` is abstractness, the share of declarations that are
interfaces or abstract classes. `D` is `|A + I - 1|`, the distance from the main sequence.

A `wiring` module reads as fully abstract because a binding container is an interface, so its
`D` is noise rather than a finding.
