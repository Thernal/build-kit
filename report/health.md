# Health

[← Module report](README.md) · generated by `./gradlew graph`

Each module gets the first condition that applies to it, so the verdict is one thing to act on
rather than a row of numbers. **Used by** counts the modules that depend on it, **depends on**
the modules it needs.

- 🔴 **Unused** — No module depends on it. Wire it into the feature that needs it, or delete it.
- 🔴 **Boundary violation** — An `api` module depends on an `impl` or `wiring` module, which inverts the split. Move the type the contract needs into an `api` module.
- 🟡 **Concrete hub** — Several modules depend on it and it is mostly concrete classes, so a change ripples widely. Extract the contract consumers actually use into an `api` module.
- 🟡 **Wide surface** — It depends on many modules, so it rebuilds often and is hard to reason about. Check whether it is doing more than one job and split it.
- 🟢 **Healthy** — Balanced coupling for its role. Nothing to do.
